# PLAN v0.19 — 외부 재생 + 자동 운영 (android)

> v0.18(담기↔소비) 후속. 외부 플레이어 연동과 보관함 자동 운영 묶음.

## 범위
- **A3 WebDAV 읽기(T-944)**: 보관함 루트 읽기 전용 WebDAV (`PROPFIND` Depth 0/1 + `GET` Range 재사용). VLC/nPlayer에서 `http://폰:8080/dav/` 재생. 쓰기(PUT/DELETE/MKCOL)는 제외. 기존 BasicAuth·IP게이트 파이프라인 그대로 적용.
- **C1 보관함 쿼터(T-945)**: 상한(GB, 0=끔) 설정 → 초과 시 오래된 파일부터 자동 휴지통 이동. 다운로드 완료·주기 체크 시점에 검사. 설정: 앱+웹.
- **C2 자동 분류(T-946)**: 확장자→폴더 규칙(영상/음악/문서/기타, 토글) → 다운로드 완료 시 자동 이동. 기존 파일 소급 적용은 제외.
- **C3 중복 감지(T-947)**: 동일 URL(정규화)·magnet(infohash) 등록 시 기존 잡 안내 후 등록 차단. 웹·앱·Share·RSS 공통.

## 제외 (v0.20로)
- 썸네일(A2)·토렌트 검색(B3)·공유링크/게스트/위젯(D).
