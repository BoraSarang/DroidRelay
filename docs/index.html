폰이 직접 받아내는
내장 웹 서버 다운로드 앱

중간 서버 없이 Android 기기 안에서 동작. 브라우저로 URL만 등록하면 스트림(m3u8/mpd)·영상·토렌트를 폰이 직접 이어받기로 받아 보관함에 저장합니다.

APK 받기 GitHub 보기
네이티브 Kotlin + Compose · 내장 서버 port 8080

간단하지만 강력한 다운로드 도구

폰의 대역폭을 그대로 활용해, 꺼져도 멈추지 않고 이어받습니다.

🎬

스트림 다운로드

m3u8(HLS)·MPD(DASH) 직접 주소 및 웹페이지 임베디드 영상 스니핑. 해상도 선택부터 진행률 표시까지.

📹

직접 영상

`.mp4/.webm/.mov` 직접 URL을 원본 그대로 보관함에 저장합니다.

🧲

토렌트

magnet·`.torrent` 지원. 시드/피어/속도 모니터링과 보관함 자동 이동.

🕸

내장 웹 서버

폰 안에서 웹 대시보드를 제공. 같은 네트워크 브라우저에서 접속해 조작합니다.

🔄

이어받기

네트워크가 단절돼도 다시 연결해 Range 기반 이어받기로 안전하게 완료합니다.

📊

실시간 진행률

FFmpeg -progress 기반으로 1초 단위 정확한 진행률·속도·예상시간을 표시합니다.

🔐

보안

WebAuth(HTTP Basic)·허용 IP 화이트리스트·HTTPS 옵션으로 웹 UI를 보호합니다.

🧠

스마트 가드

발열/배터리/저장공간 임계에 따라 다운로드를 자동 제한해 폰을 보호합니다.

🗓

스케줄·RSS·웹훅

크론 예약, RSS 자동 다운로드, 완료/실패 알림 웹훅까지 지원합니다.

3단계로 시작

별도 서버 없이, 폰 하나로 끝납니다.

1

APK 설치

Releases에서 릴리즈 APK를 받아 폰에 설치합니다.

2

서버 시작

앱에서 내장 서버를 켭니다 (기본 포트 8080).

3

웹 UI 접속

같은 네트워크의 브라우저에서 http://폰-IP:8080 으로 접속해 URL을 등록합니다.

# USB 연결한 맥/PC에서 폰의 웹 UI 열기 $ adb reverse tcp:8080 tcp:8080 $ open http://localhost:8080 # 폰 핫스팟 IP는 swlan0 인터페이스 http://192.168.x.x:8080 ← 브라우저에서 접속
