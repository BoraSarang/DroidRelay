Relay Console — 안드로이드 리디자인

Material 3 Expressive 토큰을 그대로 쓰되, 측정기(instrument) 같은 밀도로 다시 그렸습니다. 시드 컬러는 릴레이/신호를 뜻하는 딥 파인 #006B56, 숫자는 tabular numeral로 고정해 값이 흔들리지 않게 했습니다. 모든 화면은 라이트/다크 동일 구조이며, 하단 내비게이션은 6개 → 5개로 줄이고 통계·설정은 “더보기”로 묶었습니다.

Light 라이트 테마 · 대비 표준

390 × 844 · 8dp 그리드 · M3 shape (16/18/28)

Dark 다크 테마 · 같은 토큰 역할, 반전된 톤

순수 검정 대신 초록빛이 섞인 surface #0E1513

메모 — 이 문서는 구현 전 디자인 합의용 목업입니다. 실제 Compose 구현 시 MaterialTheme(colorScheme = …) 에 같은 hex 를 넣고, 폰트는 Roboto Flex(숫자 tabular), 모양은 16/18/28dp 를 사용합니다. 상태바·펀치홀은 목업 장식이며 앱 UI 가 아닙니다.
