## 2. 조사 요약 (실측)

사용자 질문: **기기 UP/DOWN 에 핫스팟 내부 트래픽까지 포함되는데, 외부로 나갔다 오는 것만 셀 수 있는가.**

### ① 지금 세는 게 뭔가

`TrafficStats.getTotalRxBytes/TxBytes` = **모든 인터페이스 합**. 실측:

```
tx  swlan0 (热点) = 47.2 GB   ← 전체의 67%
tx  rmnet* (외부)  = 23.1 GB
tx  total         = 70.2 GB   ← = 47.2 + 23.1  (정확히 일치)
```

**tx 의 67% 가 핫스팟 내부.** 사용자가 느낀 것이 맞았다.

### ② M-24 가 실패한 경로는 여전히 실패

```
run-as … cat /proc/net/dev                     → Permission denied
run-as … cat /sys/class/net/swlan0/statistics/… → Permission denied
```

### ③ ★ 숨겨진 길 — M-24 가 못 찾던 것

`TrafficStats.getRxBytes(String iface)` — **인수에 인터페이스 이름을 받는 hidden API**.
**앱 안에서 리플렉션으로 부르면 앱 uid 로 정상값**이 나온다.

> **왜 M-24 가 못 찾았나** — `adb shell` 로 테스트하면 **셸 uid** 라서 되고,
> 그게 성공한 것을 "앱도 된다" 로 착각한다. **앱 안에서 직접 읽어야 답이 된다.**

### ④ 판정 — 3구간 증분 비교

| 구간 | swlan0Δtx | rmnetΔrx | totalΔtx |
|---|---|---|---|
| 내부만 (200회) | 116,759 | 3,868,448 | 2,318,330 |
| **외부 25MB** | **6,619,775** | **43,890,914** | 21,406,525 |
| 내부만 (200회) | 1,022,106 | 5,168,953 | 2,179,866 |

②가 ①③ 대비 `swlan0Δtx` 11.6배 · `rmnetΔrx` 9.7배 — **둘이 독립적으로 움직인다.**
합으로 빼지 않고 **rmnet 을 직접 읽는다** (뺄셈은 언제든 음수가 될 수 있다).

## 4. 이번에 배운 것

### ① "기본값" 이 두 군데에서 달라야 한다

| 위치 | 기본 | 이유 |
|---|---|---|
| 클라이언트 설정 | `EXTERNAL` | 지표의 목적이 "밖으로 얼마나 씀인가" |
| 서버 파라미터 없음 | `ALL` | **안 보낸다 = 이 필드를 모르는 구버전** |

**서버·클라이언트는 따로 업그레이드된다.** 서버만 먼저 올리고 옛 클라이언트가
파라미터를 안 보낼 때, 서버가 "외부만" 으로 답하면 **조용히 다른 값이 보인다** —
"설정을 안 했는데 왜 값이 달라졌지". **가장 나쁜 종류의 실패** 다.

→ **모르는 쪽에는 예전 값을 준다.** 이 테스트가 내 잘못된 전제를 잡았다
(처음에 `assertEquals(EXTERNAL, of(null))` 라 적었고 **실패**했다).

### ② "32비트라 `intValue` 가 좁혔다" 는 틀린 가설이었다

값이 음수로 보여 단정했다. **같은 응답을 두 경로로 나눠 재현한 결과:**

```
JSON          txTotal = 71,693,545,994
intValue   →  71,693,545,994    ← 64비트 macOS 라 안 잘린다
문자열 직접 →  71,693,545,994    ← 동일
```

> **가설을 검증하지 않고 코드에 "왜냐면 32비트다" 를 주석으로 남겼다면,
> 그 주석이 다음 사람을 같은 잘못된 단정으로 몰아갔을 것이다.**

그래도 `int64Value` 를 쓰는 게 맞다 — **형이 값의 범위를 보장하는 쪽**이 옳다.
**가설이 틀렸다고 `max(0,·)` 방어를 없애면 안 된다** — 진짜 원인은 카운터 되감김이었다.

### ③ "값이 변하는 대상" 을 두 번 읽어 비교하면 증명이 안 된다

처음에 "파싱 경로 vs 서버 원본" 을 비교하려다 **언제나 다르다**는 걸 알았다.
카운터가 매 순간 증가하니까. → **같은 응답 한 번을 두 경로로만 나눠야 한다.**

### ④ 규칙을 두 벌 쓰면 테스트가 통과한 채로 틀어진다

`scopeNote` 를 처음엔 `AppModel` 에, 테스트는 **같은 문자열을 복사**해서 돌렸다.
Core 의 순수 함수(`mismatchNote`)로 옮길 수 있었다 — 의존이 없었으니까.

> **테스트는 규칙의 복사본이 아니라 규칙 자신을 검증해야 한다.**
> 복사본이면 **한쪽만 고쳐지고 테스트는 통과한 채로 화면이 틀어진다.**

### ⑤ hidden API 를 쓰는 곳은 4곳을 캐시한다

Method 조회, 볼륨 캐시, 가시성 — 1초 폴링마다 reflection 을 다시 하면
**가장 조용한 성능 저하**가 된다. `@Volatile` + 캐시로 막는다.
