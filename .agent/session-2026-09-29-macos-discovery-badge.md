# 세션 로그 — 2026-09-29 (macos, M-22 탐색 상태 표시 · M-10 점검)

## 1. 목표
사용자 지시 "다음 작업할거 있으면 작업해" — 남은 항목 중 **착수 가능한 것**을 골랐다.

| 항목 | 판단 |
|---|---|
| M-12 팔레트 | ❌ **시스템 권한 필요**(Carbon 핫키 · IME 캡처) — 사용자 승인 없이 못 진행 |
| M-10 목업 3건 | → **먼저 점검**해 실제로 남은 게 뭔지 확인 |
| M-11 탐색 표시 | ✅ **착수** — 미착수 항목이고 위험 부담이 낮다 |

## 2. M-10 점검 — 사실 3건은 이미 되어 있었다

| 항목 | 결과 |
|---|---|
| 팝오버 폭 352 | ✅ M-1 에서 반영 (`PopoverView` 63행) |
| 통계 행 | ✅ M-13 에서 **탭별** 3칸으로 구현 |
| 탭바 | ✅ M-13 반영 |
| **목업의 "온도"** | ❌ **서버에 엔드포인트가 없다** |

**온도 항목은 넣을 수 없었다.** `/api/info` 를 실측했다:

```
httpsEnabled, httpsPort, ip, port, running,
speedTotalBps, storageFree, storageTotal, version
```

**온도 필드가 없다.** 목업은 폰의 배터리/온도 센서를 가정했는데 **서버가 그 값을 주지 않는다.**
→ 넣으면 **"—" 가 항상 보이는 자리가 생기고**, 그건 정보를 더하는 게 아니라
**없는 자리를 그리는 것**이다. 넣지 않는다.

→ **M-10 은 실질 완결로 정리.** 팔레트만 M-12 로 분리.

## 3. M-22 — 탐색 상태 표시

### 왜 필요했나 — 사용자가 겪는 상황

```
아무것도 안 눌렀는데 목록이 나왔다 → "이게 내 폰이 맞아?"
```

더 나쁜 상황도 있다:

> **네트워크가 바뀌면 조용히 다른 폰에 붙어 있을 수 있다.**
> 공유기 설정으로 바뀐 건데 주소만 달라지고 아무 말 없으면, 사용자는
> **"왜 갑자기 옛날 자료 나오지"** 하고 원인을 알 수 없다.

→ 붙은 곳과 방법을 함께 말한다. **고장인지 설정이 바뀐 건지가 드러난다.**

### 규칙을 Core 에 뺐다

전략 4개 × 버전 유무 × 수동 입력이 얽혀 있다. 화면에 문자열을 바로 쓰면
**분기가 4개** 생기고 그 4개가 언제 맞는지 설명할 곳이 없어진다.
→ `DiscoveryBadge` 로 빼서 **디스플레이 없이 전부 고정**한다.

### 판단 3가지

**① 버전을 반드시 함께 보여준다** — 주소만 있으면 "이게 내 폰이 맞아?" 에 답할 방법이 없다.
**버전**이 있어야 폰 설정 화면의 숫자와 **맞춰 볼 수 있다.**

**② 수동 입력은 자동 발견과 구분한다** — 오해의 방향이 **정반대**다.
- 자동 발견 → "자동으로 붙었다" 는 **안심**
- 직접 입력 → "내가 넣은 곳" 은 **확인 필요**

`isManual` 이 전략보다 **우선**한다. 주소를 직접 넣었는데 `cached` 로 보고되면
**"자동으로 찾았다"고 거짓말**하게 된다.

**③ 빈 버전을 걸러낸다** — `cached` 경로는 프로브 없이 `version: ""` 로 `ServerInfo` 를 만든다.
그대로 붙이면 `10.38.120.211:3000 · v` 가 나온다. 사용자는 **서버가 깨졌다** 고 오해한다.
공백뿐인 문자열도 같은 취급.

### UI 배치 — 왜 따로 줄을 세웠나

헤더 오른쪽엔 **마지막 갱신 시각**(`방금 전`)이 이미 있다. 거기 붙이면
**두 정보가 한 줄에서 경쟁한다.** 어느 쪽이 움직이는지 눈에 띄고,
읽히는 쪽이 더 중요하므로 **고정된 줄로 분리**했다.

`Text("DroidRelay")` 만으로는 **어느 폰인지** 모른다. 제목과 같은 줄에 붙어 있어야
"이 앱이 누구와 붙었는가" 가 한 번에 읽힌다.

색은 글자와 같은 판단을 쓴다 — **"연결됨" 인데 주황이면 거짓말로 읽힌다.**

## 4. 진단이 화면과 같은 말을 하게 했다

`--diagnose` 에 **화면 글자를 따로 적으면 화면과 진단이 서로 다른 말을 하게 된다.**
같은 함수를 쓴다.

```
사용 전략   : 게이트웨이  (119ms)
팝오버 표시 : 10.38.120.211:3000 · v0.43.0 · 게이트웨이
빈 버전 표기 : "10.38.120.211:3000 · 저장된 주소"  ← v 가 붙지 않아야 한다
수동 입력 표기: "10.38.120.211:3000 · v0.43.0 · 직접 입력"
```

## 6. 교훈
- **목업은 되지만 서버가 못 주는 값이 있다.** 온도 항목이 그랬다.
  목업 단계에서 값을 그리지 말고 **서버 API 를 먼저 실측**했어야 한다.
  → **"값이 없으면 자리를 그리지 말라"** 는 M-16 의 "받기는 모든 파일에" 와 같은 결론이다.
- **오해를 부르는 방향이 반대인 두 상태는 반드시 다른 말을 해야 한다.**
  자동 발견(안심)과 수동 입력(확인 필요)을 같은 문장으로 뭉개면 어느 쪽도 쓸 수 없다.
